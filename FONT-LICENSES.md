# Website fonts

All site text uses **FZ Shoujin** (方正瘦金书简体), self-hosted at `site/assets/fonts/FZShouJinShu.ttf`. This is a proprietary font, not an open-source font. The user confirmed that web/embedding authorization is in place. The official license information is on [Founder Type's font page](https://www.foundertype.com/index.php/FontInfo/index/id/150.html). The font file came from the URL supplied by the user; that mirror itself has no license file.

The large brand mark uses the project's existing outlined SVG logo, so its lettering exactly matches the icon artwork. The stylesheet uses system Song-style serif fonts only as fallbacks for glyphs not present in the Shoujin font.
