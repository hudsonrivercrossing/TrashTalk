# Website fonts

Site chrome, headings, and supporting copy use **FZ Shoujin** (方正瘦金书简体), self-hosted at `site/assets/fonts/FZShouJinShu.ttf`. This is a proprietary font, not an open-source font. The user confirmed that web/embedding authorization is in place. The official license information is on [Founder Type's font page](https://www.foundertype.com/index.php/FontInfo/index/id/150.html). The font file came from the URL supplied by the user; that mirror itself has no license file.

The large brand mark uses the project's existing outlined SVG logo, so its lettering exactly matches the icon artwork. The stylesheet uses system Song-style serif fonts only as fallbacks for glyphs not present in the Shoujin font.

## Zhuque Fangsong

Article dialogue text uses **Zhuque Fangsong** (朱雀仿宋), hosted at `site/assets/fonts/ZhuqueFangsong-Regular.ttf`. This unmodified technical-preview font is from [TrionesType/zhuque](https://github.com/TrionesType/zhuque), release v0.212, and is licensed under the SIL Open Font License 1.1. The full license is included at `site/assets/fonts/ZhuqueFangsong-OFL.txt`. The upstream project labels v0.212 as a prerelease/technical preview; glyph coverage and designs may change before a final release.
