# Website fonts

The website uses two typefaces:

- **Noto Serif SC** (思源宋体 / 简体中文) is loaded from Google Fonts. It is licensed under SIL Open Font License 1.1: [Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/notoserifsc/METADATA.pb), [upstream license](https://github.com/notofonts/noto-cjk/blob/main/Serif/LICENSE).
- **FZ Shoujin** (方正瘦金书简体) is used as a self-hosted display webfont at `site/assets/fonts/FZShouJinShu.ttf`. It is proprietary, not open source. The user confirmed that web/embedding authorization is in place. The official license information is on [Founder Type's font page](https://www.foundertype.com/index.php/FontInfo/index/id/150.html). The font file came from the URL supplied by the user; that mirror itself has no license file.

The main reading text uses Noto Serif SC; FZ Shoujin is limited to the logo/wordmark accents and is served only as a webfont under the user's stated authorization.
